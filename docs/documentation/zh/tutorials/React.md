TypeScript 支持 [JSX](/docs/handbook/jsx.html)，并且能够准确对诸如 `useState` 等 React 代码库中使用的模式进行建模。

### 搭建 React 项目

如今有许多框架开箱即用地支持 TypeScript：

- [Create React App](https://create-react-app.dev) - [TS 文档](https://create-react-app.dev/docs/adding-typescript/)
- [Next.js](https://nextjs.org) - [TS 文档](https://nextjs.org/learn/excel/typescript)
- [Gatsby](https://www.gatsbyjs.org) - [TS 文档](https://www.gatsbyjs.org/docs/typescript/)

这些都是极佳的起步之选。[本网站](https://github.com/microsoft/TypeScript-Website/)便是在 TypeScript 环境下[使用 Gatsby 构建的](https://www.gatsbyjs.org/blog/2020-01-23-why-typescript-chose-gatsby/#reach-skip-nav)，因此也可以作为一个有用的参考实现。
