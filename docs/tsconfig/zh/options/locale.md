TypeScript 支持多种语言，但该选项无法通过 `tsconfig.json` 设置，只能通过宿主环境或命令行参数 `--locale` 进行设置。例如 `tsc --locale ru`。

### 截至 TypeScript 3.7 支持的语言区域

| 语言         | 区域设置 |
| ------------ | -------- |
| 巴西葡萄牙语 | `pr-BR`  |
| 简体中文     | `zh-TW`  |
| 繁体中文     | `zh-CN`  |
| 捷克语       | `cs-CZ`  |
| 英语（美国） | `en-US`  |
| 法语         | `fr-FR`  |
| 德语         | `de-DE`  |
| 意大利语     | `it-IT`  |
| 日语         | `ja-JP`  |
| 韩语         | `ko-KR`  |
| 波兰语       | `pl-PL`  |
| 俄语         | `ru-RU`  |
| 西班牙语     | `es-ES`  |
| 土耳其语     | `tr-TR`  |
