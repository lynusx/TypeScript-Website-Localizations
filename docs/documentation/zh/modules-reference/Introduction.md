本文档分为四个部分：

1. 第一部分阐述了 TypeScript 处理模块背后的[**理论**](/docs/handbook/modules/theory.html)。如果你希望能够在任何场景下正确配置模块相关的编译器选项、推导如何将 TypeScript 与其他工具集成，或者理解 TypeScript 如何处理依赖包，那么这里就是起点。虽然针对这些主题有专门的指南和参考文档，但建立对这些基本原理的理解能让你更轻松地阅读指南，并为你解决此处未具体涉及的实际问题提供一套心智模型。
2. [**指南**](/docs/handbook/modules/guides/choosing-compiler-options.html)展示了如何完成特定的实际任务，从为新项目选择正确的编译配置开始。无论对于希望以最快速度上手的初学者，还是已经对理论有深刻理解但需要针对复杂任务获取具体指导的专家，指南都是一个很好的切入点。
3. [**参考**](/docs/handbook/modules/reference.html)部分对前述部分介绍的语法和配置提供了更详尽的解读。
4. [**附录**](/docs/handbook/modules/appendices/esm-cjs-interop.html)涵盖了一些复杂主题，这些主题值得展开比理论或参考部分所允许的篇幅更加详尽的深入解释。
